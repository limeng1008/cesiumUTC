# 局部电离层剖切分析

2026-09-10，在现有三维电离层页面交付。沿用原主题、数据管理与 SAMI3 入库，不另建页面或数据副本。

## 使用方法

1. 从数据管理打开已入库时刻，或在三维电离层选择山东模拟数据。
2. 对全球数据先点“山东范围”，也可绘制矩形研究区域。需要明显的低值蓝色，可应用“科研切片预设”。这些操作不会将 SAMI3 换成模拟数据。
3. 在“显示模式”选择：
   - 经向剖面：固定经度，南→北展开；拖动经度滑块或输入数值。
   - 纬向剖面：固定纬度，西→东展开；拖动纬度滑块或输入数值。
   - 路径剖面：点“绘制剖切线”，在地面依次点击起点、终点。移动鼠标预览，Esc 取消，完成后点“聚焦剖面”。
4. 高度裁剪同时控制剖面上下边界。水平切片、竖直剖面独立开关，可叠加；单独查看竖直剖面时取消“显示切片”。
5. 开启空间探针后，点击三维幕墙或下方二维图。两者联动显示经纬度、高度、Ne；路径剖面还显示距起点的距离。
6. 二维图标题可折叠。900 px 以下剖面视图上下排列，地图、二维图、参数和探针通过页面内滚动访问。

## 数据与颜色口径

二维与三维使用同一个 `SectionGrid`，默认 129 个路径节点 × 128 个高度节点。值从当前加载的标准/精细体网格插值得到，不直接采样原始 NetCDF，不以增加纹理像素冒充源数据精度。二维有效颜色不与地图混色，三维保留透明叠加，因此视觉亮度可能不同，但共用同一标量与 RGB 色带。

- 全数据：当前加载时刻、当前网格的有效范围，不是源文件所有时刻的范围。
- 当前区域：研究区域及高度裁剪范围内的有效样本，包含裁剪边界插值；体渲染、水平切片、竖直幕墙、二维图共用该范围，不逐层归一化。
- 手动：输入 Ne 下限、上限后使用手动范围。改范围仅影响显示，不修改科学值。

无数据透明，不补零；log 模式排除非正数；linear 支持零值与小数。常量场保留原始值说明并微量扩展显示跨度。合法的极窄非恒定范围不再强制扩大。数据源/时刻切换清除旧剖面取值、路径与色标缓存，恢复全数据范围。

取样先检查科学值有效性、阈值和实际纹理 alpha。三维点击竖直剖面优先，再考虑水平切片与体数据。透明处不能返回看似有效的数值。鼠标点选受屏幕像素精度影响；相同 SectionGrid 坐标使用相同采样计算，不从颜色反算。

## 第一版边界

- 一次激活一个竖直剖面。
- 地图画线为两点 WGS84 最短测地线，不是多顶点折线或自由手绘曲线。过近/近对跖端点拒绝，天空不作为地面点。
- 研究区域与数据有效域仍限制路径；域外透明，不进行外推。
- 三维幕墙用分段网格近似曲面，并非完整原始体素体渲染；高度未夸张。
- 全局低分辨率网格在山东上空可能表现为宽而平滑的色带，真实 SAMI3 不会人为生成模拟场的中心红核。
- 近距离聚焦时区域包络可部分出画，使用缩小按钮查看完整范围。
