# 时空变化分析

入口：`/time-variation`，或从数据分析页点击“分析时空变化”，自动关联同一数据管理文件。

## 使用

1. 选择文件、开始和结束UTC时间（不按电脑本地时区换算）。
2. 输入固定经纬度/高度，或在地图点选位置；需要局部统计时点击“绘制区域”选两个角点，也可输入边界。西界大于东界表示跨日期变更线。
3. 设置高度范围，点击“开始分析”。读取期间可取消；修改任何条件会取消并清空旧结果，须重新开始。
4. 查看固定位置Ne、区域平均/最大Ne变化，以及时间—高度图。图表支持线性和对数，蓝色低、红色高，热图全时段共用动态色标。
5. 逐时刻表可跳到该任务的单时刻分析；展开剖面明细可按时刻查看64个高度的原始采样值，零值和缺失不受颜色筛选影响。

## 数据口径与限制

- 只读数据管理中成功入库的任务，不自动入库、不回退Mock。读取metadata与二进制后核对source、volumeId、timestamp及数据范围。
- 完整源文件时间索引决定横轴。未入库、失败、取消以及无有效值都留空；零是有效线性值，对数图不显示零。不会跨缺口连线或插值。
- 热图列宽由相邻源时刻中点划分，只表达该时刻的样本，不代表其间连续变化。只有一个时刻时显示单点/单列，不能判断趋势。
- 使用入库standard网格；例如本地文件源高度90–2200km，但入库网格90–1000km。表格和结果说明提供真实网格范围，范围以外不外推。
- 点值和高度剖面复用三线性插值。区域均值为有效非负网格中心算术均值，不是面积/体积加权；局部选框与固定采样点独立。
- 单次最多256源时刻，逐帧串行、每帧60秒超时；只保留摘要与64个高度样本，不保留全时段体网格。单帧失败不阻断其他时刻。
- 不含三维播放、独立TEC专题、报告导出或后台自动入库。
