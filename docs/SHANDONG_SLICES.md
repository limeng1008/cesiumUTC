# 山东局部三维电离层切片

运行地址：http://127.0.0.1:3100/ionosphere。默认来源为「山东局部 · 确定性模拟」。

## 实现范围

- 默认斜视山东，示意省界高亮；域为 114–122°E、34–40.5°N。
- 100 / 200 / 300 / 400 km 四个 WGS84 真实高度曲面网格，无高度夸张。
- RectangleGeometry + Primitive + 电子密度纹理；包络由顶底、四壁和边线组成。本模式不创建 VoxelPrimitive，不是完整体渲染。
- 81 × 65 × 61 的确定性数据网格，双平滑高斯核心、边缘平滑衰减、300 km 垂向峰值。刷新结果相同，非观测数据。
- 共用线性蓝→青→绿→黄→红色标，范围从整个当前网格有效极值计算，约 1e8–7.47e11 m⁻³。不对各层独立重标定。
- 默认像素 alpha 约 0.252–0.45，高值更明显。采用距离排序透明混合；重叠后的屏幕颜色不等于单层原始颜色，不能用于反算 Ne。

## 交互

左侧可隐藏切片、调全局透明度、修改层高及显示高度范围；数值高度输入在回车或失去焦点后提交。控制面板可滚动。

点击视线中最近的可见切片，在右侧读取经纬度、高度、Ne；可降低最高高度以访问下层。探针按同一网格插值，隐藏或完全透明的切片不参与拾取。「山东斜视」恢复默认相机。

## 地理参照与限制

省界缓存于 `web/public/data/shandong-boundary.geojson`，来源：https://geo.datav.aliyun.com/areas_v3/bound/370000.json（阿里云 DataV，示意边界）。已保留署名，不宣称权威最新测绘边界；正式发布前需核实边界及影像使用授权。

Esri World Imagery 为可选联网底图，失败时使用项目自带 Natural Earth。切片模拟数据和省界不依赖外部数据接口。

原全球 Mock / SAMI3 路径保留；本轮视觉验收针对山东局部模式，未将本效果宣称为真实 SAMI3 分析结果。未增加时间轴、卫星、预警或后台业务。
