# SAMI3 单时刻文件接入

已支持用户下载的 `sami3_regulargrid_elec_density_2019Apr25_v01.nc`（本地文件名为 `content`）。原文件不修改、不复制、不上传，仅离线读取一个时刻，生成供现有体渲染使用的小网格。

## 数据核验

- 来源：https://zenodo.org/records/8140040 ，物理模型输出，不是实测。
- 文件 497,680,368 bytes；MD5 `1d50235481d481c58636554b3a15a3a6` 与发布方一致。
- SHA256 `d5bd27d232977b1c18c8d1728783320b9ed0a544e7ebf00d4b3a8f105976b25d`。
- `dene0(nt,nlat,nlon,nalt)`，144 个时刻，10 分钟间隔。
- 原始经度 0..354°（60格），纬度 -89..88.5°（72格），非均匀高度 90..2200 km（100格）。
- 原 Ne 单位 cm⁻³，导入时乘 10⁶ 转换为 m⁻³。

## 导入命令

在仓库根目录：

```sh
uv sync --frozen
uv run python scripts/import_sami3.py '/Volumes/应用磁盘/ChromeDownLoad/content' --time-index 0
```

当前导入 `2019-04-25T00:00:00Z`，只提供静态快照，不新增时间轴。后续显式重新运行脚本可更换快照。

产物保存在被 Git 忽略的 `data/ionosphere/sami3/`。分别重采样为72×36×32和144×72×64，输出高度90..1000km；经度周期，纬度/高度不外推，缺测为-999。`validDomain` 是原始覆盖与输出范围的交集，CPU查询和GPU裁剪均遵守。

产物采用不可变版本目录，最后原子更新current.json。旧版本保留，以便metadata与binary请求之间发生导入时仍可用volumeId取得对应版本。没有网络上传接口，也不接受任意文件路径的HTTP请求。

## 来源 API 与页面

`GET /api/v1/ionosphere/sources` 返回已安装来源。文件导入后，首次打开页面默认使用SAMI3；可手动切换Mock。原有metadata/binary接口添加`source=mock|sami3`，默认mock保持兼容；binary带`volumeId=metadata.id`。所有请求沿用token鉴权。

页面显示“SAMI3模型数据”、静态UTC时刻、90km高度下限。来源变更先清除旧体数据和标签，再加载新数据；显式选择SAMI3失败不会静默回退Mock。

## 色标与数值

图例不写死min/max。初次加载或重置取**当前重采样体数据**的有效极值（排除-999）；用户修改Ne范围后，色标跟随该显示范围。单独高度裁剪或切片不重新缩放色标，以便不同视图可比较。

| 网格 | 最小 Ne（m⁻³） | 最大 Ne（m⁻³） | 二进制大小 | noData格数 |
| --- | ---: | ---: | ---: | ---: |
| 标准 | 77,094,936 | 1,712,879,435,776 | 331,776 bytes | 0 |
| 精细 | 75,809,096 | 1,717,111,095,296 | 2,654,208 bytes | 9,216 |

根据用户确认，默认色带已改为蓝→青→绿→黄→红，刷新及重置均生效；Viridis和Scientific仍为可选项。颜色取决于局部Ne，透明度叠加后并不要求每个视角都同时出现所有颜色。

在116.391°E、39.907°N、300km，标准体数据三线性值为225,755,195,603.15204 m⁻³，页面显示2.26×10¹¹；直接对原生NetCDF网格插值得224,533,283,918.08325，两者约差0.54%。这是该点重采样差异的示例，不是全域精度保证。页面探针查询当前重采样网格，不声称原生源文件精度。
