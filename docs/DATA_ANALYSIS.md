# 数据分析工作台（第一阶段）

入口：`/analysis`。支持 `?importId=<已成功入库任务ID>`；三维电离层页右上方“数据分析”可带入当前任务，分析页也可返回相同任务的三维视图。

## 使用

1. 选择数据管理中的文件与成功入库 UTC 时刻。首次无指定链接时选择可用文件的最新已入库时刻；无可用任务则显示导入提示。无效任务不回退到其他任务或示例数据。
2. 直接查看全数据统计，或填写矩形经纬度/高度范围并点击“应用范围并分析”。东界小于西界表示跨日期变更线。
3. 地图“绘制区域”：依次点击地球表面两个角点，Esc 或取消按钮退出。完成后显示青色包络轮廓并更新统计；清除区域返回全数据范围。
4. 点击地图或输入经纬度并点击“采样剖面”，显示采样点与橙色虚线；青色实线为各高度的区域平均 Ne。可切换对数/线性横轴。
5. 下方表格显示逐高度最小/最大/均值、有效点数与选定位置插值；展开完整剖面可查看高度边界样本。
6. 切换同文件时刻保留研究范围与采样点；更换文件重置范围和点。请求期间清空旧结果；被替代的请求和离开页面后的响应不能重新发布结果。

## 科学口径与限制

- 复用 `/ionosphere/volume` 的已入库标准网格（当前 SAMI3 为 72×36×32），不是原始 NetCDF 的全分辨率统计。使用相同元数据、Float32解码、单位与版本校验，不新增后台入库逻辑或修改用户文件。
- Ne 单位 m⁻³，高度 km，经纬度 WGS84，时刻 UTC；SAMI3 是模型结果，不代表实测。
- 统计范围由网格中心是否落在选区/高度范围/数据有效域内决定，不对边界格做面积比例或插值补点。很小的区域可能没有网格中心，明确返回“无有效数据”。
- 最大/最小值和均值只计有限非负且不等于 noData 的值；零值有效、缺失不按零计算。均值为等权网格点算术均值，非面积/体积加权。
- “最大值所在高度”是当前选区所有网格值的最大值位置，不是 hmF2。并列最大值取 Z/Y/X 顺序的首个样本。
- 区域平均高度剖面在每个网格中心高度分别统计；点剖面复用三维探针的三线性插值，包括高度裁剪边界，不根据图像颜色反推。缺失邻居产生空值，不跨空值连线。对数轴不显示零值，可切换线性轴查看。
- 表格/统计卡展示5位有效数字；计算不使用这些舍入后的显示值。单一高度曲线轴留出±1km显示空间，不增加采样值。
- 第一阶段不包含时间序列、独立TEC专题、报告导出或多区域对比。
