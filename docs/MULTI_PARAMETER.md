# 多参数数据链路：第一阶段交付

验收日期：2026-09-20。范围为受控原始标量场的识别、入库与三维联动；不是全部专业分析功能已完成。

## 使用

1. 打开 `/data-management`，上传符合当前 SAMI3 布局的 NetCDF。已有文件可点“刷新变量目录”，只更新解析目录，不重算成功产物。
2. 查看每个变量的源名称、源单位、标准单位、维度、形状和不可用原因。选择研究参数，再做单时刻或批量入库。
3. 点击“打开三维”，或在 `/ionosphere` 选择文件、参数与已入库时刻。URL 使用不可变 importId，刷新后恢复对应参数和时刻。
4. 切换参数保持当前 UTC；该参数在当前 UTC 没有成功任务时不会偷偷跳时刻，也不会沿用旧网格。可主动选择该参数已有时刻，或到数据管理入库。

支持参数：Ne、Te、Ti，以及明确物种的 O+、H+、He+、N+、NO+、O2+、N2+ 离子数密度。密度标准单位 m⁻³，温度 K；温度默认线性、密度默认对数，色标范围来自实际加载网格。体、水平切片、竖直剖面和空间探针共用参数及单位。切换时清空旧采样与数值范围，保留同文件的研究区域、高度裁剪与剖面位置。

## 科学与格式边界

- 当前只支持 `nt,nlat,nlon,nalt` 四维独立标量、全球周期等间距经度及既有 SAMI3 坐标约定；不宣称支持任意 NetCDF、额外物种轴、区域经度源网格或曲线网格。
- 受控别名、明确单位和物种声明共同校验。冲突别名、未知单位、物种冲突、字符串/复合变量均有不可导入原因，不猜物种编号。特定离子物种温度不能当通用 Ti。
- 密度零值保留，负值/非有限值/填充值为缺测；温度非正值为缺测。对数显示排除零，不把缺测填成零。整数型带填充值的温度先转浮点再保留缺测。
- 首时刻全缺测不禁用整个结构有效的参数；各时刻导入时分别校验有效数据，无值时刻明确失败，不阻止后续有效时刻。
- 现有数据分析、时空变化及首页 TEC/F2 仍是 Ne 专题，主动过滤并拒绝温度等非 Ne 输入。TEC/F2 算法扩展、变化率/梯度/背景偏差和 GNSS 闪烁等后续专题未在本轮新增。
- 入库仍采用单 API 进程的持久化串行队列；本轮未增加多实例队列协调。
