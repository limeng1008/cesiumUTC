# CesiumUTC web application

This directory contains the Vue 3, Pinia, Naive UI, and CesiumJS frontend for CesiumUTC.

From this directory:

```bash
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

See the repository [README](../README.md) and [setup guide](../SETUP.md) for the backend, validation commands, data workflow, and scientific limitations.
