## [0.1.0] - 2026-09-20

### Added

- CesiumJS native 3D ionosphere volume rendering with scientific value and altitude controls.
- Single- and multi-altitude geodetic slices with shared color mapping and regional clipping.
- Spatial probes, regional statistics, longitude/latitude sections, and drawn vertical sections.
- Temporal, profile, multi-parameter, and derived ionosphere analysis workflows.
- SAMI3 NetCDF inspection, normalization, managed import, batch processing, and cancellation.
- Deterministic mock data for reproducible local exploration and tests.
- English-first documentation, repository safety checks, community files, and continuous integration for the open-source launch.
